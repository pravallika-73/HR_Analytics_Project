# HR Analytics Dashboard

This project analyzes employee attrition using Machine Learning and visualizes HR insights using Streamlit.

## 📊 Project Overview

The goal of this project is to help HR teams predict employee attrition and understand workforce patterns.

## 🚀 Features

* Employee attrition prediction
* Machine learning model
* HR analytics dashboard
* Visualization of attrition distribution
* Model accuracy display

## 🛠 Tech Stack

* Python
* Pandas
* Scikit-Learn
* Streamlit
* Matplotlib / Seaborn

## 📂 Project Structure

HR_Analytics_Project
│
├── data/
├── src/
├── app.py
├── requirements.txt

## ▶ Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
